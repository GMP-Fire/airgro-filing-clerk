Privacy Policy

Filing Clerk — last updated 7 September 2026

Filing Clerk is a personal, single-user automation. Its only user is its author, who is also the owner of the Google account it accesses. It is not offered to anyone else and collects no data from anyone else.

What it accesses

  • Gmail (read-only): message metadata and attachments from a defined list of senders, in order to identify documents of record.
  • Google Drive: to read its own configuration file and to write those documents into folders the account owner already maintains.

What it does with that data

Attachments are copied from Gmail to Google Drive within the same Google account. Files are never opened, parsed or inspected — password-protected documents are stored exactly as issued.

What it does not do

  • No data is sent to any third party, server or service outside Google, other than a task title and reference written to the owner's own Todoist account when a filing destination is missing.
  • No data is sold, shared, or used for advertising, profiling or model training.
  • No email is sent, deleted or modified.
  • No data is retained outside the owner's own Google account. The script keeps no database and no copies.

Where it runs

On GitHub Actions, using OAuth credentials held as encrypted repository secrets in a private repository controlled by the account owner.

Revoking access

The account owner can revoke access at any time at myaccount.google.com/permissions, which immediately and permanently stops all access.

Contact

Questions about this policy go to the address listed as the developer contact on the Google Cloud project.
